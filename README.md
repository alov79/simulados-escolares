# Missão Nota 10

Portal de estudos gamificado para o 4º ano, com revisão, simulados, XP, moedas, recompensa proporcional, progresso salvo no navegador e recursos de ajuda no estilo Show do Milhão.

## Versão publicada

- Página inicial do portal
- Missão de Matemática com 25 questões
- Adição, subtração, multiplicação, gráficos e tabelas
- Assistente, Universitários e Eliminar alternativas
- PWA com service worker
